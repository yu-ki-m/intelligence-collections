# Interview Guide

このガイドは、曖昧な回答を具体化するための質問パターン集である。

## 1. 目的

曖昧:
「効率化したい」

具体化:
- 何の時間を減らしたいか
- 誰の作業時間か
- 現在値はいくつか
- 目標値はいくつか
- その改善が売上・コスト・品質のどれに影響するか

## 2. 対象範囲

曖昧:
「全部」

具体化:
- 開始イベント
- 終了イベント
- 対象組織
- 対象顧客
- 対象拠点
- 対象製品
- 対象チャネル

## 3. Owner

曖昧:
「チームで見る」

具体化:
- 最終責任者
- 実行責任者
- 承認者
- 相談先
- 通知先

## 4. KPI

曖昧:
「品質を上げる」

具体化候補:
- defect rate
- escape rate
- rework rate
- first pass yield
- SLA breach
- customer complaint
- recovery time

## 5. 例外

曖昧:
「例外は特にない」

具体化:
- 緊急
- 権限不足
- データ不足
- 外部障害
- 顧客都合
- 重複
- 期限切れ
- 取消
- 差戻し
- 再開

## 6. 非機能

曖昧:
「速く」

具体化:
- 画面応答
- API応答
- バッチ完了
- 同時利用者
- 最大件数

## 7. セキュリティ

曖昧:
「普通で」

具体化:
- 認証方式
- 権限粒度
- tenant isolation
- audit
- retention
- encryption
- admin override
