# Traceability Rules

Every major system requirement must trace back to a business purpose.

Required chain:

Business Goal
→ Observed Problem
→ Root Cause
→ Management Requirement
→ TO-BE Model Element
→ State / KPI / Decision
→ Capability
→ Functional / Non-Functional Requirement
→ Data / Permission / Interface
→ Acceptance Criteria

Any requirement that cannot be traced to an upstream reason is a removal candidate.
