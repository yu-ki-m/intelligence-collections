# Trust Coach — Claude Code Skill

エンジニア、開発リーダー、プロダクトオーナーの「信頼される立ち振る舞い」を、実際の状況に即して壁打ち・会話練習・振り返りする Claude Code 向けスキルです。

## インストール

- 個人用（すべてのプロジェクト）：`~/.claude/skills/trust-coach/`
- プロジェクト専用：`<project>/.claude/skills/trust-coach/`

`SKILL.md` と `references/` を含む `trust-coach` ディレクトリごとコピーしてください。

## 使い方

```
/trust-coach 顧客に遅延を報告するとき、どう振る舞うべきか壁打ちしたい
/trust-coach 私が開発リーダーで、部下の設計を強く指摘したい。ロールプレイして
/trust-coach POとして営業からの急な要望を断りたい
/trust-coach 昨日の会議での私の発言を厳しく振り返って
```

実際にメッセージを送る、リポジトリを変更するなどの外部アクションは含みません。

## 対話設計：状況把握を優先

初回の相談では、すぐに提案せず、理解した事実を要約して最重要の確認質問を原則1問だけ行います。出来事・関係者・役割と権限・既存対応・目標・制約を必要な深さまで確認した後、行動案の比較やロールプレイへ進みます。緊急の被害抑止、またはユーザーが明示的に質問不要とした場合のみ例外です。

## 主体性の設計（改訂）

状況把握では「責任・裁量・期待水準」も確認します。役割に応じて、報告だけで終わらず、影響範囲・既存仕様・対策案・推奨判断・実施責任まで考えるコーチングに変更しました。重大事象の早期共有は維持しつつ、調査や解決を上司に丸投げしません。詳細は `references/ownership.md` を参照してください。
