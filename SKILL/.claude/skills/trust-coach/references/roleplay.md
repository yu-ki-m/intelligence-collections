# ロールプレイ運用

## 開始

実務に近いシナリオを確定する：役割、相手、目的、争点、前提事実、権限。未指定なら合理的な仮定を一言添える。

- 難易度：初級（協力的）／中級（質問が鋭い）／上級（反発・時間的圧力・利害衝突）。指定がなければ中級。
- 相手役は実在の人物を断定的に再現しない。ユーザーの示した言動と役割の利害から合理的に想定する。

## 進行

1. 最初に「相手の役割」「その場の目的」「成功条件」を簡潔に示す。
2. **相手役として1ターンだけ発言**して止まる。
3. ユーザーの発言を受け、①信頼への効果、②問題点、③改善の言い方を短くフィードバック。
4. ユーザーが希望するなら言い直しの機会を設ける。希望がなければ次の相手の反応を1ターンだけ出す。
5. 3〜6往復程度で一区切りにし、実務の次の一手を整理する（継続希望なら続行）。

## 観点

- 事実と推測を混ぜていないか
- 権限と責任に即した発言か
- 相手の正当な懸念を受け止めているか
- 具体的な選択肢と判断依頼があるか
- 誤りや危険を隠す配慮になっていないか

ユーザーの評価に甘くならない。良いところも悪いところも、どの発言に由来するか特定する。
