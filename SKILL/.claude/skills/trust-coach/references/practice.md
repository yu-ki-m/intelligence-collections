# 継続トレーニング

## 一回の振り返り

1. どんな状況で誰と会話したか
2. 自分が実際に何を言い、何を行ったか（推測で補わない）
3. 相手の実際の反応（観測）と、その意味の仮説を分ける
4. 信頼の6軸のうち何が強まり、何が弱まった可能性があるか
5. 次回の行動を1〜2個だけ変更する

## 行動実験の設計

形式：`[いつ・どの状況で] [どの行動を] [どう確認するか]`

例：
- 「遅延の可能性を確認した当日中に、影響・選択肢・次回報告時刻を送る。2週間の実施率を振り返る」
- 「レビューで反対するとき、まず相手の狙いを要約して認識を合わせる。会議メモで実行回数を確認する」
- 「POとして要望を受けたら、実装案より先に顧客課題と期待成果を一度確認する」

## 定期レビュー

- 良くなったこと：観察可能な事実
- 引き続き難しいこと：再現条件と阻害要因
- 相手の反応：確かめた事実／解釈
- 次の1〜2個の習慣

点数は学習の補助に過ぎない。対人信頼そのものを数値化できたと装わない。
